# Coppermine — redesign prototype

An unofficial design prototype for [coppermine.is](https://coppermine.is), built as a concept
by [SNDR Studio](https://sndr-studio.pages.dev). This is **not** the real Coppermine website
and is not affiliated with or endorsed by Coppermine.

Product imagery, video and the logo belong to Coppermine and are referenced from their own
CDN for demonstration purposes only. Marked `noindex`.

Static site: vanilla HTML/CSS/JS, GSAP + Lenis.
